# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive data exposure issue in SYNAPTIK, please do NOT open a public issue.

Instead, please send an email directly to **fr4n0bbb@gmail.com**.

Please include:
- A description of the issue and potential impact
- Steps or a minimal reproducible example
- Any relevant logs or environment details

We will acknowledge receipt within 48 hours and work with you on a resolution prior to any public disclosure.
